# Statische Unternehmenswebsite auf AWS

Infrastructure as Code für eine statische Website, ausgeliefert über Amazon S3 und
Amazon CloudFront, erreichbar unter einer eigenen Domain mit eigenem TLS-Zertifikat.

Portfolio im Kurs Cloud Programming (DLBSEPCP01_D), Aufgabe 1.
IU Internationale Hochschule, Studiengang Softwareentwicklung.
